Forge UI style guide

Every element here is live and uses forge-ui.css and forge-ui.js. Rules for each are in DESIGN.md.

Color tokens

Use the variables, never raw hex, so light and dark mode both work. Orange is the accent (focus rings, current page, badges), never body text.

Typography

Archivo for headings, Inter for text, IBM Plex Mono for numbers, dates, IDs and scores.

Page title (Archivo 26)

Section title (Archivo 18)

Panel title (Archivo 16)

Body text, Inter 15/1.5. Write in plain, sentence-case language; say what happens, not what the system is.

Note or caption, 12px muted.

Buttons

One primary button per area. Ghost for secondary actions; red only for deleting or overwriting.

Forms, tag inputs and pickers

Labels sit above fields. Multi-value fields use the tag input (Enter, comma or Tab adds; paste a comma list; Backspace removes the last).
